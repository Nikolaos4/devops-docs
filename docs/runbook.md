# Руководство по эксплуатации

## Назначение

Проект `devops-docs` содержит учебную документацию
и автоматизированные проверки качества.

## Проверка качества

Python-код проверяется инструментом Pylint.

Проверка выполняется автоматически через GitHub Actions.

## Сборка документации

Документация создаётся с помощью MkDocs.

Команда локальной сборки:

```bash
mkdocs build --strict --site-dir site
